JuiceBox

My most ambitious side project to date. After buying my first EV the nerd inside of me wanted to keep track of the running costs and compare them to my old fuel car. I started off using a spreadsheet but eventually that became tedious and difficult to keep updating especially as I mainly did it on my phone.


So I decided to build JuiceBox, to start just for personal use but after I developed some interesting features, used the app formyself for a while and the app itself became more polished, I decided I would publish it to the Apple App Store as I assumed many other EV owners would make good use of it.


JuiceBox currently has nearly 200 downloads, 5 paying users and already on version 1.2 that added several new features including a way to scan public charger screens to automatically add charging session values to a new charging log, csv and json file mapping for importing charging data from other sources and a calculable way of estimating battery health and usable capacity for the vehicle.
